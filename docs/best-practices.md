## 信息密度与留白平衡

### 黄金法则：高密度但不拥挤

**好的示例：**
- 每个模块框内都有子内容（缩略图、公式、标注）
- 使用 8-12px 的微间距分隔元素
- 关键信息突出，次要信息淡化

**坏的示例：**
- 大的空白方框只写一个词
- 过度的装饰性元素
- 元素之间间距过大（>20px）

### 实用技巧

1. **嵌入缩略图** - 在模块框内添加小型可视化：
   - 卷积核可视化
   - 特征图变化
   - 注意力模式
   - 数据流形状

2. **维度标注** - 在所有主要箭头上标注：
   ```
   [B, C, H, W] → [B, 2C, H/2, W/2]
   ```

3. **公式标注** - 在关键操作旁添加数学公式：
   ```
   Attention(Q, K, V) = softmax(QKᵀ/√d)V
   ```

## 配色使用原则

### 三色原则

**最多使用 3 种彩色 + 灰色系：**

| 颜色数量 | 适用场景 |
|---------|---------|
| **1 种彩色** | 极简期刊（Nature/Science） |
| **2 种彩色** | 大多数顶会论文 |
| **3 种彩色** | 复杂多分支架构 |
| **>3 种彩色** | 仅用于类别极多的可视化（如语义分割） |

### 边框而非填充

**学术配图的惯例是：**
- ✅ 白色填充 + 彩色细边框
- ✅ 仅用于高亮的小区域用彩色填充
- ❌ 大面积彩色填充（看起来像幻灯片）

**好的示例：**
```
┌─────────────┐
│   Module    │ ← 白色填充，蓝色边框
│  [缩略图]   │
└─────────────┘
```

### 灰度兼容检查

**在提交前务必验证：**
1. 将图片转为黑白
2. 确认所有元素仍可区分
3. 关键信息不依赖颜色

## 字体与排版

### 字体选择

| 风格 | 推荐字体 | 适用场景 |
|------|---------|---------|
| **经典学术** | Computer Modern, Latin Modern | Nature/Science, 数学密集型 |
| **现代工程** | Arial, Helvetica | CVPR, ICCV, ECCV |
| **现代 ML** | Nunito, Poppins, Quicksand | NeurIPS, ICML, ICLR (pastel 风格) |

### 字体大小层级

```
标题/节标签：    14-16pt (bold)
模块名称：       10-12pt (regular)
标注/维度：       8-10pt (regular)
公式下标/上标：    6-8pt
```

**关键原则：** 缩小后（如论文打印的 2 栏宽度），最小字体 ≥ 6pt。

## 图表类型选择

### 按用途选择

| 信息类型 | 最佳图表类型 | 示例 |
|---------|------------|------|
| **整体流程** | 总体框架图 | Figure 1 |
| **层级结构** | 网络架构图 | 编码器-解码器 |
| **核心创新** | 模块细节图 | 注意力机制 |
| **性能对比** | 柱状图/折线图 | FID、准确率 |
| **消融实验** | 多面板网格图 | 各组件贡献 |
| **数据行为** | 热力图/t-SNE | 注意力模式 |

### Figure 1 设计原则

**Figure 1 是论文最重要的图：**

1. **概念清晰** - 读者看完应该理解"这篇论文做了什么"
2. **信息完整** - 包含输入、处理、输出全流程
3. **视觉吸引** - 适当的密度，不要太空也不要太挤
4. **色盲友好** - 使用经过验证的调色板

**常见结构：**
```
[输入] → [处理阶段 1] → [处理阶段 2] → ... → [输出]
    ↑          ↑              ↑
  缩略图      缩略图          缩略图
  标注        标注            标注
```

## 多面板图组织

### 网格布局

**常见布局模式：**

```
2x2 网格（最常见）：
┌─────┬─────┐
│ (a) │ (b) │
├─────┼─────┤
│ (c) │ (d) │
└─────┴─────┘

1x3 横向对比：
┌─────┬─────┬─────┐
│ (a) │ (b) │ (c) │
└─────┴─────┴─────┘

3x1 纵向流程：
┌─────┐
│ (a) │
├─────┤
│ (b) │
├─────┤
│ (c) │
└─────┘
```

### 面板标签

**位置：** 左上角或左下角

**格式：**
- `(a)`、`(b)`、`(c)` - 最常用
- `A.`、`B.`、`C.` - 有些期刊偏好
- **字体：** 加粗，比正文大 2pt

### 统一风格

**多面板图务必保持一致：**
- 配色方案统一
- 字体大小统一
- 线条粗细统一
- 间距统一

## AI 生成工具提示词技巧

### 四层提示词结构

**层次 1: 全局描述**
```
A highly detailed, information-dense academic paper [类型] diagram in the style of
top-tier [会议] publications. The diagram illustrates [主题概述], arranged as
[布局描述].
```

**层次 2: 分区详细描述**
```
=== SECTION NAME ===
White background panel with light gray border...
- Module 1 with steel blue border
- Module 2 with warm orange border
- Connection arrows labeled with dimensions
```

**层次 3: 全局标注**
- 维度标注沿主要箭头
- 反馈环路（虚线箭头）
- 图例位置
- 跨区域连接

**层次 4: 风格规格（关键！）**
```
=== STYLE SPECIFICATIONS ===
- Background: Pure white #FFFFFF
- Font: Clean sans-serif (Computer Modern style)
- Line weight: 1.5pt for main borders, 0.75pt for secondary
- Resolution: 300 DPI, 16:9 aspect ratio
- NO GRADIENT, NO SHADING, NO PHOTOREALISTIC ELEMENTS
- Vector illustration, technical diagram style
```

### 工具特定优化

#### NanoBanana / Gemini
- 极其详细的英文提示
- 强调 "vector illustration"、"flat design"
- 明确说 "no photorealistic elements"

#### DALL-E 3
- 添加 "in the style of a technical diagram for an academic paper"
- 指定确切色值
- 可以理解复杂的布局描述

#### Midjourney
- 使用 `--style raw` 参数
- 添加权重：`vector diagram::5 academic::5`
- 使用 `--no 3D, gradient, shading` 排除不需要的元素

### 质量检查清单（生成后验证）

- [ ] 信息密度：每个模块框内都有子内容
- [ ] 色彩克制：仅使用 2-3 种色彩
- [ ] 白色主导：≥70% 面积为白色
- [ ] 边框而非填充：模块用白色填充 + 彩色/灰色细边框
- [ ] 维度标注：所有主要数据流箭头上都标注了维度
- [ ] 公式标注：关键操作旁有对应数学公式
- [ ] 缩略图嵌入：至少 50% 的模块内嵌入了单色/双色缩略可视化
- [ ] 灰度测试：图片在黑白打印时仍可完整阅读

## 迭代改进流程

### 图生图工作流

1. **生成初版** - 使用详细提示词生成第一张图
2. **识别问题** - 对照检查清单找出不足
3. **局部修正** - 使用图生图功能，用文字指令修改：
   ```
   "Make the arrows thinner, add dimension labels on all arrows,
   embed small thumbnail visualizations inside each module box"
   ```
4. **反复迭代** - 直到满足所有质量标准

### 寻求反馈

**在提交前建议获取以下反馈：**
1. **色盲同事** - 验证可区分性
2. **非领域专家** - 验证概念清晰度
3. **导师/合作者** - 验证内容正确性
