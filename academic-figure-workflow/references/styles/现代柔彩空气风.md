# 现代柔彩空气风 (Pastel Airy UI)

## 职责边界

本 profile 表达**白卡片、floating token、轻边界和较多留白**的 airy UI 语法。它不等于所有现代机器学习论文图，也不适合需要大面积柔彩语义区、强描边和手绘叙事的 illustrated modular 图；后者使用 [编辑手绘模块风.md](编辑手绘模块风.md)。

## 代表论文与配图来源 (Representative Paper & Figure)

- **SWE-agent (Yang et al., ICML 2024)**: *Figure 2 (SWE-agent ACI Overview)* — 纯白浮动卡片、CLI 终端仿真交互视窗、文件树结构、Diff 补丁与优雅柔彩状态 Pill。
- **Voyager (Wang et al., NeurIPS 2023)**: *Figure 1 (An Open-Ended Embodied Agent with LLMs)* — 纯白卡片式 Agent-Environment 交互流、Skill 迭代库与高留白空气感布局。
- **ReAct (Yao et al., ICLR 2023)**: *Figure 1 / Figure 2 (Synergizing Reasoning and Acting)* — 纯白浮动卡片、Reasoning/Act/Obs 的轻量悬浮 Token 流与现代 UI 交互感。
- **Reflexion (Shinn et al., NeurIPS 2023)**: *Figure 1 (Reflexion Architecture)* — 白色浮动卡片、Actor/Evaluator/Self-Reflection 循环与轻量状态 Pill。

## 适用场景

- token flow、概念 pill、界面式信息关系
- 用户或参考图明确使用白卡片和轻阴影
- 内容可由少量卡片、浮动 token 和曲线表达

不要因为 venue、年份或模块数量自动选择本风格。

## 参考图优先

若用户提供参考图，记录卡片表面、阴影强度、圆角、留白、token 密度、字体和连线。参考语法优先于以下默认值；只复用视觉原则，不复制文字、logo、品牌资产、拓扑或结果。

## 与 illustrated modular 的快速区分

| 属性 | Airy UI | Illustrated modular |
|---|---|---|
| 主表面 | 白卡片 | 柔彩语义大区 |
| 分隔 | 轻边框或克制阴影 | 1.5–2.5px 同色深描边，无阴影 |
| 视觉中心 | token/card 关系 | 非对称 hero mechanism |
| 嵌套 | 通常无 | 最多一层 subcard |
| 图标 | 小型、稀疏 | 可承担叙事的受控线稿 |
