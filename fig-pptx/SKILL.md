# fig-pptx

把一张已经接受的学术示意图做成可编辑 PPTX。文字是文本框，底下的图片层没有这些字。源 PNG 不修改。

## 入口

只在两件事都成立时开始：用户接受了这张图，并且明确要可编辑 PPT。`fig-draw` 交付后的询问得到肯定，也算明确要求。

- 图还没交付，或用户还没回答要不要做 PPT：停。
- 用户不满意这张图：停。改图交给 `fig-draw`。改完并再次交付之后，由 `fig-draw` 再问一次。
- 这是要保住数据点形状的结果图，而不是示意图：停，并说明这条路径会重画框架和图标。

## 步骤

1. 读 `references/layers.md`。完成条件：抠图底色、三张图片层的提示词和 `layout.json` 字段都按那一页来。
2. 在本 skill 目录建一个新的运行目录，把源图复制进去。完成条件：源文件本身没有被改写。
3. 用图像工具看源图，再生成背景、框架、图标表。完成条件：三层都是新生成的图；没有从源图裁一块下来，也没有用形状或代码把卡片、图表、图标画出来。
4. 按源图里字的样子运行 `scripts/pick_font.py --style`，把打印出的家族写入每段 `font`，再跑 `references/layers.md` 里的抠图、切片、校验和合成命令。完成条件：`pick_font.py` 退出码为 0，`layout_guard.py --strict` 退出码为 0，并写出 `.pptx`。漫画字缺 Comic Neue 时，脚本安装 `fonts-comic-neue` 后再选；其它风格列出已安装字体后退出时，停，不改用另一类字体。
5. 打开合成预览，和源图并排看一次。字压住图标，或同一句话出现两次，就改 `layout.json` 再合成一次。然后停。完成条件：交付 `.pptx` 的路径，并说明和源图还差在哪里。
